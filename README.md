# 蓝豆 LanDou · 桌宠与代码特效

无需构建的纯静态创意网页。下载仓库后，用任意静态服务器指向本目录即可预览。

## 页面入口

- `index.html`：独立欢迎首页，可选择进入桌宠或代码特效。
- `workspace.html#playground`：蓝豆桌宠工作台。
- `workspace.html#cat`：橘团桌宠工作台，是侧边栏中的独立栏目。
- `workspace.html#effects`：代码特效画廊。
- `workspace.html#light`：一笔一画，移动鼠标或滑动手指，让预设卡通形象逐笔完成。
- `workspace.html#agreement`：同意用户协议，中文网页闯关游戏，侧边栏第 07 项。
- `workspace.html#dodge`：极限闪避，侧边栏第 08 项，60 秒霓虹弹幕生存挑战。
- `workspace.html#thrill`：刺激吓人，内部独立切换过山车俯冲、玻璃桥跃下、林间突然惊吓。
- 四项均为本地实时模拟，不加载外部实拍影片。支持拖动转头和全屏观看。
- 过山车中段包含完整垂直圆环，镜头与车体一起倒悬并复位；蹦极使用重力、绳索弹力和阻尼计算连续下坠及多次回弹。
- 场景使用本地生成的岩壁 / 树皮纹理、天空环境反射、动态阴影、透明玻璃和分层植被；仍为浏览器三维场景，不等同于专业游戏引擎的照片级渲染。
- 工作台内的视图切换会写入浏览器历史，可使用前进、后退返回上一视图。

## 功能

- 「极限闪避」支持热身、心跳、极限三档难度。每局 60 秒，依次进入交叉火力、旋涡弹幕、激光封锁；激光有虚线预警与安全缺口。鼠标移动、触屏拖动、WASD 或方向键控制青色光点；空格或下方按钮发动短暂无敌冲刺，冷却 2.4 秒。3 格护盾耗尽则结算，坚持到最后获得通关奖励。
- 擦弹基础分 80，2 秒内连续擦弹最高 5 倍；收集能量 +250 分并刷新冲刺冷却。最佳得分按难度分别保存到本机，存储不可用时仍可游戏。音效默认关闭，可选全屏。P / Escape 暂停；切换栏目、窗口失焦或进入后台会自动暂停，需主动继续。游戏中锁定难度，结算后可切换；「重开」返回准备界面，也可重新选择难度。
- 游戏与绘制：[dodge-arena.js](./scripts/features/dodge-arena.js)；界面：[dodge-arena.css](./styles/components/dodge-arena.css)。纯 Canvas 本地游戏，按栏目懒加载，无外部素材或新增依赖。

- 「同意用户协议」街机版参考 Steam 原作及[中文实况录像](https://www.bilibili.com/video/BV1KrfrBkEoT/)中的协议机关，由本站独立实现 12 种协议关卡和最后的心跳跑酷。包含逃跑按钮、真假弹窗、同意打地鼠、接物、转盘、三连同意机、洗牌追踪、打砖块、飞行、变色连点和弹幕生存。每局按难度分组打乱顺序，部分机关随机布局。页面保留原作链接，非官方移植，不包含原作全部关卡或素材。
- 休闲模式失误罚时 5 秒并重试本条；经典模式一次失误从第 1 条重新开始。单关练习室可直接体验全部 13 个小游戏，练习成绩不计入纪录。每关点「准备好了，开始」后才启动本关倒计时和总计时。完成全部协议后解锁最终跑酷，通过后结算。
- 难度分为「入门 / 挑战 / 噩梦」，默认挑战，刷新后记住所选难度。三档分别调整反应窗口、目标次数、干扰数量、速度和容错；高难度增加移动门洞、多方向弹幕、耐久砖块和加速跑酷。游戏模式决定失误后的重试方式，可以与任意难度组合。
- 顶部「时间限制」开关默认开启，可在游戏中或暂停面板切换。关闭后取消本关超时失败，总用时继续记录；重新开启从原剩余时间继续。刷新会记住设置。开关不改变反应机关和弹幕生存目标。
- 支持提示、暂停、音效开关（默认关闭），以及鼠标、触屏和键盘操作。切换栏目、后台或窗口失焦时自动暂停，返回需主动继续；暂停同时停止物理模拟与计时，并释放按键状态。刷新页面会重新开始。本机最佳成绩按「难度 × 模式 × 限时设置」分别存入 `localStorage`，一局中使用过不限时后按不限时记录，存储不可用时仍可正常游戏。
- 游戏管理：[agreement-arcade.js](./scripts/features/agreement-arcade.js)；关卡与物理：[agreement-challenges.js](./scripts/features/agreement-challenges.js)；难度规则及提示：[agreement-difficulty.js](./scripts/features/agreement-difficulty.js)；样式：[基础布局](./styles/components/agreement-game.css)、[街机界面](./styles/components/agreement-arcade.css)。纯静态模块，按栏目懒加载，不依赖外部服务或新增安装包。

- 「一笔一画」提供猫咪、蓝舌石龙子、熊猫、西瓜、桃子、小兔六套水彩插画，按轮廓、神情、花草、水彩四阶段绘制。电脑在纸面移动鼠标即可推进，无需按住；手机使用手指滑动；聚焦画布后可用空格或方向键操作。输入通过逐帧插值平滑推进，停止移动后最多用 240 毫秒收尾；离开画布或页面进入后台立即暂停，没有自动播放。
- 支持三档落笔节奏、成画预览、单个角色重新绘制、1200×1020 PNG 导出（保留纸纹和当前绘画状态）。每个角色独立保存本次页面会话中的进度，切换角色、栏目或窗口尺寸不会丢失；刷新页面会重置。预览不会改变实际进度。
- 六张 AI 生成水彩画稿保存在 `assets/sketch-v2/`，角色配置位于 [sketch-characters.js](./scripts/data/sketch-characters.js)。画稿加载时提取轮廓并缓存图层，绘制时增量描线、柔化上色边缘，再用 Canvas 合成纸纹与画面，无需外部图片服务。

- 蓝豆和橘团两个独立桌宠栏目，每只都有 9 个动画组、57 个可单独选择的细分姿势。
- 纯手动动作模式，不会随机切换动作。
- 支持播放、暂停、上一帧、下一帧和播放整组。
- 支持拖动桌宠，双击蓝豆可切换到挥爪动作。
- 可折叠的侧边栏与桌宠 / 代码特效双视图，并可随时返回欢迎首页。
- “绽放”3D 花体特效：高质感透明花朵由 Canvas 控制盛开、呼吸和景深粒子，可重播并调整速度。
- 适配桌面和手机浏览器，使用任意静态服务器即可运行（例如 `python -m http.server 4173`）。

## 目录结构

“刺激吓人”使用本地 Three.js 实时生成场景，支持拖动与方向键转头、暂停、重置、全屏和可选风声。点击开始后才播放，切换栏目、切换场景、页面进入后台或按 Esc 时停止当前播放。四个场景独立；突然扑脸只在第三个场景出现，高空蹦极包含倒数、自由落体、绳索回弹和云端摇摆。玻璃桥与蹦极为虚拟场景，并非景区实拍；当前没有接入 360° 视频或 WebXR 头显模式。

- `styles/`：全局设计变量、布局与组件样式。
- `scripts/components/`：侧边栏等通用界面组件。
- `scripts/features/`：桌宠与特效画廊功能入口。
- `scripts/effects/`：每一种代码特效独立一个文件夹。
- `scripts/data/`：桌宠动作数据。
- `ju-tuan-cat/`：橘团的 Codex 桌宠包、网页图集与完整生成工作目录。

## 图片资源

全部生成图片都保存在 `assets/`：

- `assets/generated-strips/`：基础定妆图和原始动作条。
- `assets/frames/`：57 张透明 PNG 拆分帧。
- `assets/previews/`：9 个 GIF 动画预览。
- `assets/spritesheet.png`：透明 PNG 图集。
- `assets/contact-sheet.png`：全部动画帧接触表。
- `assets/screenshots/`：桌面版与手机版截图。

网页运行时使用根目录中的 `spritesheet.webp`，尺寸为 1536×1872，包含透明通道。

橘团网页运行时使用 `ju-tuan-cat/spritesheet.webp`；可编辑源动作条、透明拆分帧、GIF 预览、接触表和校验结果保存在 `ju-tuan-cat/work/`。同一套桌宠包也安装在 Codex 的 `pets/ju-tuan-cat/` 目录中。
