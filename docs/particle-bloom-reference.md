# 视频参考与三种花型

参考为用户提供的本地 c7d31265a092430bdf6c04048b5c0d76.mp4。实际时长 10.66 秒、1324×720、30 fps；前约 8 秒为花朵，后约 3 秒为平台片尾。已抽取逐秒画面，工作目录 output/flower-reference/contact-sheet.jpg 可查看对照。

参考花朵从已局部打开的外瓣开始，花心整体圆润饱满，逐渐舒展。网站为满足用户此前的完整盛开要求，补充合拢花苞起点，不复刻平台片尾、水印和代码编辑器背景。

本轮将旧的图片形变牡丹、玫瑰卡片换成可旋转的原创程序化曲面花朵，保留它们在目录中的位置。三种花型共用薄纱材质与纵向细线，几何分别设计：

- 莲花：46 片花瓣，圆润花心，长而通透的外瓣。
- 牡丹：71 片重瓣，较宽的花瓣和更明显的褶皱边缘。
- 玫瑰：41 片螺旋排列花瓣，内瓣旋拢，玫瑰粉配色。

每个卡片均提供 8 秒盛开、五阶段选择、拖动进度、暂停、重播、三档速度和拖动旋转。按可见区域延迟创建场景，隐藏栏目或切到后台时停止渲染。欢迎首页、桌宠、心动宇宙保持不变。

验证命令：node --test pet-work/blue-tongue-skink/web/scripts/tests/flower-bloom.test.mjs

五项测试覆盖三种花型的 GPU 输入顶点有限值、索引范围、曲面与线条共享进度、页面独立控件、播放结束停止和重播回到起点。均已通过，源码语法检查通过。这些测试不验证着色器输出的视觉形状。

本轮使用浏览器截图对照视频抽帧，检查了莲花展开、牡丹和玫瑰盛放。花瓣改为每帧在 GPU 中计算连续曲面，外到内错开展开，保留圆润包裹的内瓣；细化花缘，降低线条亮度，增加横向包裹与少量非对称尺寸。每片花瓣使用 48×64 曲面分段和 65 条纵向细线。上下左右拖动或方向键可调整两个轴的视角。

本地内置浏览器在播放时通过 requestAnimationFrame 计数采样：三种花型分别测得约 60 FPS（场景在视口内、当前设备和窗口尺寸）；不是跨设备保证，也不是 GPU 硬件计时。按时间推进，暂停、离屏或后台时停止循环。参考视频本身为 30 FPS。

目前是依据视频形态重建的可交互程序化模型，已检查实际画面，但花瓣排列仍比参考规则，不声称像素或逐帧一致。
